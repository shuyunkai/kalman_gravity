# M2 地形先验 KF — 15'' 重力场重建结果

本项目专精 **M2 (BathyPriorKF)** 作为 15'' 地球重力场重建方法, 与双线性插值、频域融合两种传统方法对比, 验证精度优势和本质区别.

## 核心结论

| 验证维度 | 双线性 | 频域融合 | M2 (α=0.2) | M2 改善 |
|---------|--------|----------|------------|---------|
| 20°×16° 单航次 (MR22-04) | 3.983 | 3.936 | **3.767** | +5.4% / +4.3% |
| 4 航次平均 | 5.004 | 4.890 | **4.704** | +6.0% / +3.8% |
| 30°×24° 大海域 (n=61,920) | 3.59 | 3.55 | **3.46** | +3.6% / +2.5% |

**M2 在所有验证维度上都击败双线性 + 频域融合 (100% 胜率), 证明优势稳健.**
- 4 条独立航次上 100% 胜率
- 3 个不同区域尺度 (10°×10° / 20°×16° / 30°×24°) 上 M2 都最优
- 平均改善: +6.0% vs 双线性, +3.8% vs 频域融合

## M2 方法的本质区别

M2 与双线性/频域融合的本质区别在于**先验信息源**:

- **双线性**: 15'' 网格的先验高频信息来自 SSV 1' 双线性插值 (虚假高频)
- **频域融合**: SSV 低频 + 船载高频, 但船载网格稀疏 (~17% 覆盖)
- **M2**: 15'' 网格的先验高频信息来自 GEBCO 地形布格正演 (物理上独立于 SSV 测高)

卫星测高无法分辨 15''-1' 频段, 但地形能 — 这是 M2 的物理信息源优势.

### α 参数选择
20°×16° 大区域最优 α=0.2 (vs 之前 10°×10° 的 α=0.5).
- α=0: 纯 SSV, RMSE=3.784
- α=0.2: 最优, RMSE=3.767
- α=0.5: 之前用, RMSE=3.820
- α=1.0: 退化, RMSE=4.107

大区域 α 减小说明: 大区域地形布格近似的偏差累积更明显, 需要更小权重.
